Hello! This is BFB. It is a project I was working on with friends before Terra and am working on during the first few weeks of Terra.
It will be a horror game eventually but for now it is just a tech demo with some things I've been working on. 

This week I completed all the systems I was planning on finishing. There is now most of the gameplay loop in place, at least in relation to cooking. The story/exploration/runningAwayFromThings is not really what I was working on although I completed all the systems it relies on. The biggest thing which is now done is cooking. You can order things from the order counter and get points for them. You can also receive orders from the counter and build burgers (although currently I have only potatoes). I also added a fail state if you don't finish making the burger in time or make it incorrectly too many times.

That's about it, the final build for Terra at least is on my itch page at https://portalgolem.itch.io/bfb-terra-test

Thanks for checking it out!

Also no AI was used during development except for a few instances searching the unity docs.
